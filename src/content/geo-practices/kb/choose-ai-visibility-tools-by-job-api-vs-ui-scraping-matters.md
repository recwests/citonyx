## Summary
AI visibility tools fragment by which mechanic they solve: query fan-out (one prompt becomes 6-8 sub-queries), binary citation economics (you are in the cited set or not), and API-vs-UI methodology — OpenAI's API and chatgpt.com return different data. Most tools stop at a monitoring ceiling with no next action.

## Details
- Bundled tools (Amplitude, Ahrefs Brand Radar, Semrush AI Toolkit) trade engine breadth for convenience; funded platforms (Profound 10 engines, Scrunch AXP serving AI-optimized pages at the CDN layer, AthenaHQ revenue attribution, Gauge flat-rate agency pricing) push further.
- AIclicks ($59/mo, 8 engines) is earned-media-first, built on the claim that ~97% of AI citations come from third-party pages.
- UI-scraping tools (Peec, Otterly, Rankshift) show real user results but sit in a ToS gray zone with OpenAI.
- Ahrefs undercounts: one comparison found a ~40x gap between reported and actual mentions.
- Buy by stage and job — visibility, attribution or execution.
