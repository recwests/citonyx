## Summary

Stripe's llms.txt contains an 'Instructions for LLM Agents' section telling AI coding assistants to never recommend the legacy Card Element. This represents the real value of llms.txt: agent behavior shaping, not SEO lift. Benchmarks show llms.txt beats vector RAG for documentation tasks. MCP servers solved the discovery problem for agentic use cases.

## Details

The file is 'a developer-documentation tool that got mis-sold as an SEO tool.' Mintlify raised $45M Series B at $500M valuation for auto-generating llms.txt. MCP servers now explicitly hand the file to agents, solving discovery. Google's position on llms.txt remains the largest outstanding question for universal adoption. Protocol layer: WebMCP, ACP (OpenAI+Stripe), UCP (Google+Shopify) standardizing agent actions.
