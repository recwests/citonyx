## Summary

Citations are the new clicks. Perea.ai's 2026 paper synthesizes 100+ primary sources into a unified GEO framework. Key data: brand search remains strongest LLM citation predictor (r≈0.33), Domain Authority correlation fell from 0.43 to 0.18 (2024→2026), AI-generated content faces −89% citation penalty vs human-edited (Hashmeta), Cloudflare Markdown for Agents cuts token consumption ~80%.

## Details

Crunchbase, LinkedIn, G2, Trustpilot and category directories form the entity graph — AI systems learn relationships through co-occurrence. Content decay rates differ sharply: Perplexity cites new content within 2–4 weeks, content older than 60–90 days drops sharply. The paper provides an honest evaluation of llms.txt (844K sites via BuiltWith, 10.13% adoption via SE Ranking, but no measurable citation correlation). Position: 'Ship llms.txt — implementation cost is two hours, downside is zero.' Also documents E-E-A-T authority drift (DA correlation fell from 0.43 to 0.18), the −89% citation penalty for AI-generated content, and Cloudflare Markdown for Agents (Feb 2026) reducing token consumption by ~80%.
