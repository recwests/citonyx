## Summary
Surfer ran 1,000 prompts through consumer UIs and their nearest APIs across ChatGPT, Perplexity, Gemini, AI Mode and AI Overviews, collecting 13,779 answers. Brand sets overlapped 15.5-23.8% raw and 21.3-31.6% after name canonicalisation, and page-level source overlap fell to 4.8-6.2% on ChatGPT.

## Details
- Data collected 4 August 2026 across 14 model-and-method combinations; ChatGPT's API named 13.8 brands per answer versus 7.9 in the interface, and wrote 2.05x more words.
- Its UI cited 12.1 sources versus 3.1 via API, while Perplexity inverted (19.5 API versus 10.27 UI); domain overlap peaked at 26.7% for Perplexity and fell to 4.8% for ChatGPT.
- Practical read: audit how any visibility tool collects data, because API-only dashboards can report mentions no buyer ever sees.
- Caveat: vendor study by a scraping-based tool, one sample per prompt, approximate model parity.
