## Summary
Google retired FAQ rich results on May 7, 2026, but FAQPage schema is still parsed and consumed by AI engines for citation extraction. Presenc tracking found pages with structured FAQ sections earn 55-85% more citations on conversational queries than prose-only pages (strongest on Perplexity +80% and ChatGPT browsing +70%), with FAQPage schema adding another 20-25%. OpenHermit reports 28-40% citation lift; Ranqo reports FAQPage schema increases Perplexity direct-answer retrieval by +31%. The visible rich result is gone, but AI extraction value remains.

## Details
FAQPage schema remains valid Schema.org — Google still parses it for page understanding. The May 7 retirement only removed the visible rich result from SERPs, not the schema's value for AI extraction. Five to eight well-scoped FAQ items outperform shorter and longer blocks; 15+ items dilute extraction priority. Questions mirroring real user phrasing earn ~35% more citations than generic framing; FAQ sections above the fold are extracted ~40% more often. LLMs read JSON-LD as text, so the visible Q&A passage is what gets cited — keep schema and rendered text in sync (spaceandstory.co, 2026). Frase reported 3.2x AI Overview inclusion for FAQ pages; Goodie's 2.2-million prompt analysis found FAQ schema increased Perplexity direct-answer retrieval by +31%. Google explicitly warns against invisible FAQ tricks — schema must match visible content.
