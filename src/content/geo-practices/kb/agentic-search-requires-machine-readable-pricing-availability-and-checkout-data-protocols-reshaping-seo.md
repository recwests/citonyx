## Summary

Search Engine Land (2026 predictions, confirmed mid-2026): OpenAI+Stripe's Agentic Commerce Protocol (ACP), Google+Microsoft's Web Capabilities Protocol (WebMCP, Chrome early preview Feb 2026), and Google+Shopify's Universal Commerce Protocol (UCP, 20+ launch partners including Target, Walmart, Visa) mean AI agents can now discover AND transact. Sites without machine-readable pricing, availability, and checkout data are skipped by AI agents. Crystal Carter (Wix): 'The so-called messy middle is now managed by AI. If you don't build for compliance, you're not in the game.'

## Details

- OpenAI open-sourced Agentic Commerce Protocol (ACP) with Stripe — Shopify enables checkout with 1 line of code.
- WebMCP (Google+Microsoft): sites declare available actions like 'add to cart' or 'book a demo.' Chrome early preview Feb 2026.
- UCP (Google+Shopify): full commerce journey — discovery, checkout, post-purchase. 20+ launch partners.
- Samanyou Garg (Writesonic): '810M daily ChatGPT users. AI stops recommending and starts buying. The user never leaves the conversation.'
- 810M daily ChatGPT users + 1.5B Google AIO MAU.
- Practical takeaway: structure pricing, availability, and product data in machine-readable formats (JSON-LD + protocol compliance). Audit for ACP/WebMCP/UCP readiness.
